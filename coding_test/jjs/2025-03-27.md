[백준 2075번 (Heapq)] https://www.acmicpc.net/problem/2075
<details> <summary>Code 단순히 리스트를 연장하는 방식. (메모리오버)</summary>

  ```python
  import sys
  input = sys.stdin.readline
  
  n = int(input())
  
  lst = []
  for _ in range(n):
      arr = list(map(int, input().split()))
      lst.extend(arr)
  
  lst.sort(reverse=True)
  
  print(lst[n-1])
  ```

<details> <summary>Code Heapq 우선순위</summary>

  ```python
  import sys
  input = sys.stdin.readline
  
  import heapq
  
  n = int(input().strip())
  
  heap = []
  for _ in range(n):
      arr = map(int,input().split())
      for a in arr:
          # heap의 크기 n으로 유지
          if len(heap) < n:
              heapq.heappush(heap, a)
          
          else:
              if heap[0] < a:  # 제일 작은 수는 방출
                  heapq.heappop(heap)
                  heapq.heappush(heap, a)
          
  # n번째로 작은 수 방출
  print(heap[0])
  ```

[백준 1302번 (dictionary)] https://www.acmicpc.net/problem/1302
<details> <summary>Code</summary>

```python
import sys
input = sys.stdin.readline

n = int(input().strip())

dict = {}
for i in range(n):
    book = input().strip()
    
    dict[book] = dict.get(book,0) + 1

max_dict = max(dict.values())

answer = []
for key, value in dict.items():
    if value == max_dict:
        answer.append(key)
        
answer.sort()
print(answer[0])
```

[백준 16439번 (문제읽기 난해함)] https://www.acmicpc.net/problem/16439

<details> <summary>Code</summary>
    
```python
import sys
input = sys.stdin.readline


from itertools import combinations

n, m = map(int,input().split()) # n: 사람 수, m: 음식 수
like = [list(map(int,input().split())) for _ in range(n)]  

#              음식       a   b   c   d   e
# 첫번째 사람의 음식 선호도 1   2   3   4   5
# 두번째 사람의 음식 선호도 5   4   3   2   1
# 세번째 사람의 음식 선호도 1   2   3   2   1

# a, b, c 고르면 max(1, 2, 3) + max(5, 4, 3) + max(1, 2, 3)

# 최대 만족도
maxSum = 0

# 음식 3개 고르기기
for a, b, c in combinations(range(m), 3):
    tmpSum = 0
    for i in range(n):
        tmpSum += max(like[i][a], like[i][b], like[i][c])
    maxSum = max(maxSum, tmpSum)

print(maxSum)
```

[백준 1092번 (문제읽기 난해함)] https://www.acmicpc.net/problem/1092

<details> <summary>Code</summary>
    
```python
import sys
input = sys.stdin.readline

from collections import deque

# 크레인 n대
n = int(input().strip())

# 각 크레인의 무게 제한
power = list(map(int,input().split()))

# 박스 m개
m = int(input().strip())

# 각 박스 무게
weight = list(map(int,input().split()))

power.sort(reverse=True)
weight = sorted(weight, reverse=True)

t = 0
# 가장 무거운 박스를 옮기지 못할 때
if power[0] < weight[0]:
    t = -1

else:
    while weight:
        t += 1
        
        for i in range(n):
            # 가장 가벼운 상자가 현재 크레인보다 무거우면 패스
            if weight and power[i] < weight[-1]:  # 상자가 남아있다면면
                continue
            
            for j in range(len(weight)):
                if power[i] >= weight[j]:
                    weight.pop(j)
                    break    # 하나만 제거
print(t)
```
